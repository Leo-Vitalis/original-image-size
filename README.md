## Description

Add-in for Excel Online which automatically resizes images to their original size upon pasting and gives the option to restore the size of any selected image. 

## Installation

Download `manifest.xml` and upload it in Excel for Web via Home -> Add-ins -> More Add-ins -> My Add-ins -> Manage -> Upload. Click on the `Original Image Size` button to initialize it for the first time. You can close the side panel, the add-in will start monitoring automatically on subsequent loads.
