## Description

Excel for Web add-in which automatically resizes images to their original size upon pasting and gives the option to restore the size of any selected image. 

## Installation

Download `manifest.xml` and upload it in Excel for Web via Home -> Add-ins -> More Add-ins -> My Add-ins -> Manage -> Upload. Click on the `Original Image Size` button to initialize it for the first time. The task pane may be closed, and the add-in will start the monitoring automatically on subsequent loads.
